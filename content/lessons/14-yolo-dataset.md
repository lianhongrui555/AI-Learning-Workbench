# 数据集、标注与训练/验证划分

> 本节目标：理解 YOLO 数据集目录、标签格式、归一化坐标以及训练集/验证集的划分原则。

## 一句话理解

数据集是教材，标签是标准答案。YOLO 要学的不是“图片压缩包”，而是一张图片里有哪些目标、它们分别在哪里。

## 核心概念

- **images**：图片文件。
- **labels**：每个图片对应的标注文件。
- **类别编号**：例如 0 表示 person，1 表示 car。
- **归一化坐标**：坐标除以图片宽高，范围通常在 0～1。
- **训练集**：用于更新模型参数。
- **验证集**：用于观察模型在未见数据上的表现。
- **数据泄漏**：验证集或测试集内容混进训练集，导致评估虚高。

YOLO 常见标签行格式：

```text
class cx cy w h
```

例如：

```text
0 0.5 0.5 0.2 0.3
```

这表示类别 0 的目标中心在图片中央，宽度占 20%，高度占 30%。

## 代码阅读示例

```python
line = "0 0.5 0.5 0.2 0.3"
parts = line.split()
print(parts[0])
```

阅读重点：

- `split()` 把一行文本拆成列表。
- 第一列通常是类别编号。
- 后面四列是中心点和宽高。
