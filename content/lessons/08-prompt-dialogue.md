# Prompt 工程与多轮对话

> 本节目标：学会把目标、背景、格式和限制说清楚，并理解多轮对话如何携带上下文。

## 一句话理解

Prompt 不是咒语，更像给同事布置任务。你说清楚目标、背景、格式和限制，对方才更容易交出符合要求的结果。

## 核心概念

- **目标**：到底要模型做什么。
- **背景**：它需要知道哪些前提。
- **格式**：要普通段落、表格、JSON 还是代码。
- **限制**：字数、语气、不能做什么、必须引用什么。
- **多轮对话**：服务端用对话编号把前后消息串起来。
- **系统提示词**：长期生效的角色和规则。

## 必须掌握的代码/命令

```python
prompt = """
目标：把下面的文字总结成三点。
背景：读者是零基础学习者。
限制：每点不超过 25 个字。
格式：使用 1、2、3 编号。

文字：人工智能正在改变很多行业，但学习时应该先理解基本概念。
"""
print(prompt)
```

## 代码阅读示例

先不要运行代码，直接阅读并尝试判断它做了什么：

```python
topic = "机器学习"
prompt = f"请用三点解释{topic}"
print(prompt)
```

阅读提示：

- 先找变量分别保存了什么。
- 再追踪每一行执行的顺序。
- 最后判断输出、错误或参数变化。
