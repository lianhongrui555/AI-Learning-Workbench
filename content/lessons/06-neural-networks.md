# 神经网络与深度学习基础

> 本节目标：理解神经元、层、激活函数、损失和反向传播的直觉。

## 一句话理解

神经网络像一条多层加工流水线。每一层都对数据做一次变换，最后输出预测结果。训练就是不断比较结果和答案，再把误差反馈回去调整参数。

## 核心概念

- **神经元**：接收输入、做加权计算、输出结果的单元。
- **层**：把很多神经元组织起来。
- **激活函数**：加入非线性，让网络能学复杂规律。
- **损失函数**：衡量预测和正确答案的差距。
- **反向传播**：计算每个参数应该往哪个方向调整。
- **深度学习**：使用较多层的神经网络。

打比方：一层层加工就像先识别线条，再组合成形状，最后识别为一张猫的图片。

## 必须掌握的代码/命令

```python
# 用一个简单的加权和模拟神经元。
inputs = [1.0, 2.0, 3.0]
weights = [0.2, 0.4, 0.1]
bias = 0.5

output = sum(x * w for x, w in zip(inputs, weights)) + bias
print("神经元输出：", output)
```
