# 向量、相似度与概率直觉

> 本节目标：用地图坐标和投票比例理解向量、相似度和概率。

## 一句话理解

向量就像地图上的一个坐标点；相似度就是比较两个点离得近不近；概率就是用数字表达“这件事有多可能”。

## 核心概念

- **向量**：一组有顺序的数字，例如 `[0.2, 0.8, 0.1]`。
- **维度**：向量里有多少个数字。文本 Embedding 往往有几百到几千维。
- **距离**：两个向量之间的距离越小，通常代表内容越相似。
- **余弦相似度**：看两个向量的方向是否接近。
- **概率**：例如“明天下雨的概率是 70%”。

打比方：把三句话放进一张地图，聊天气的句子聚在一起，聊代码的句子聚在另一片区域。Embedding 就是在给内容找坐标。

## 必须掌握的代码/命令

```python
# 两个二维向量，可以想象成地图上的两个点。
point_a = [1.0, 2.0]
point_b = [1.2, 1.8]

# 计算简单的欧氏距离。
distance = ((point_a[0] - point_b[0]) ** 2 + (point_a[1] - point_b[1]) ** 2) ** 0.5
print("两点距离：", distance)
```
