# 数据、特征、标签、训练与推理

> 本节目标：认识数据、特征、标签、训练集、测试集、推理和评估之间的关系。

## 一句话理解

数据是教材，特征是题目里的线索，标签是标准答案，训练是学习，推理是考试，测试集是以前没见过的模拟考卷。

## 核心概念

- **样本**：一条数据，例如一封邮件、一张图片或一条天气记录。
- **特征**：描述样本的输入信息，例如邮件的关键词、图片的像素、当天的温度。
- **标签**：我们希望模型学会预测的答案，例如“垃圾邮件/正常邮件”。
- **训练**：让模型从训练数据中调整参数。
- **推理**：模型训练完成后，对新输入做预测或生成。
- **过拟合**：模型把训练题背下来了，换一道新题就不会了。

打比方：如果训练集是练习题，测试集就是考试题。用练习题反复练可以，但不能把考试题拿来背答案。

## 必须掌握的代码/命令

```python
# 用一个小列表模拟“特征”和“标签”。
samples = [
    {"features": [1, 0, 1], "label": "通过"},
    {"features": [0, 0, 0], "label": "不通过"},
]

for sample in samples:
    print(sample["features"], "->", sample["label"])
```
